Working hypothesis

ALE's tolerance shift is most plausibly explained not by large-scale genome restructuring — the two genomes are substantially collinear once duplicate content is corrected for — but by a small number of point mutations concentrated in aldehyde- and furan-detoxification machinery, headlined by a high-impact frameshift in an aldehyde oxidase gene. This is consistent with selection under lignocellulosic hydrolysate, whose dominant inhibitory compound, 5-hydroxymethylfurfural (HMF), is cleared primarily through aldehyde oxidation/reduction pathways. The case is suggestive, not yet closed: the single most direct confirmatory test — whether the same loci shifted under HMF-only selection — has not yet been run on a coordinate-matched reference (§7).

Cross-genome alignment shows a largely collinear relationship — 59 alignment blocks across the two assemblies, mostly same-orientation with a handful of inversions, no gross rearrangement, consistent with a direct descendant under selection rather than a divergent strain. Self-alignment of each genome against itself independently turned up multiple near-100.0%-identity duplicate blocks tens of kilobases long in both strains — too perfect to be ordinary heterozygosity, more consistent with retained duplicate/haplotig sequence, the same signal purge_dups corrected for above. GenomeScope2's model fit to the k-mer spectrum was middling (62–68%, not the >90% a clean two-peak diploid model would give) — read as corroborating evidence that duplication, not classical heterozygosity, is shaping this spectrum.

02

Candidate genotypic changes

Three ALE-specific variants, called against the HS2 reference and annotated via SnpEff, cross-referenced to UniProt/GO/KEGG through the strain's existing Trinity/Trinotate transcriptome annotation, converge on a single biological theme: aldehyde and furan detoxification — mechanistically the most direct route by which a cell tolerates HMF, the principal inhibitor in lignocellulosic hydrolysate.

PEL1 / SLADptg000019l:1,297,961 · C→T · SNPhigh relevance

MODERATE impact missense variant. SLAD encodes succinate-semialdehyde dehydrogenase (NAD⁺) — oxidizes succinic semialdehyde, a reactive aldehyde intermediate of the GABA shunt, to succinate. A coding change here sits directly in an aldehyde-clearance pathway.

GO:0004777 succinate-semialdehyde dehydrogenase activityGABA catabolic processkeyword: aldehyde detox / dehydrogenase
ODP25 / EPHAptg000051l:296,388 · C→A · SNPmoderate relevance

MODERATE impact missense variant. ODP25 is a pyruvate dehydrogenase complex component (dihydrolipoyllysine-residue acetyltransferase) — central carbon metabolism, upstream of the TCA cycle. EPHA carries epoxide hydrolase activity and a "response to toxic substance" annotation. Plausible as a direct detox link or a flux-rebalancing response to metabolic stress; less immediately specific than the other two, and the only candidate with any overlap in the HS19 (unrelated stressor) comparison — see §4.

SYGM2 / GLOXptg000082l:318,837 · AAC→A · INDELhighest relevance

HIGH impact frameshift variant — the single most consequential change in the candidate set. GLOX carries aldehyde oxidase activity (GO:0004031) — an enzyme that acts directly on aldehyde substrates, the same chemical class as HMF itself. A frameshift is a strong-effect mutation (likely loss- or altered-function), the kind of change most readily connected to a discrete phenotypic shift under aldehyde selection pressure.

04

Full analytical pipeline

Complete, command-level detail for independent reproduction and evaluation. Tool versions and exact parameters are given at each stage; rationale is given wherever a non-default choice was made.

Sequencing

PacBio Revio HiFi. HS2: 23.95 Gb raw, 1,374,677 reads, N50 19,686 bp, Q20 96.26%, Q30 91.04%, GC 56.25%. ALE: 28.59 Gb raw, 1,714,417 reads, N50 18,680 bp, Q20 96.47%, Q30 91.51%, GC 56.94%.

Organelle depletion

Chloroplast + mitochondrion reference (C. sorokiniana SLA-04-derived). minimap2 -ax map-hifi against the organelle reference; organelle-mapping read IDs removed with seqkit grep -v before assembly. This step also resolved a reproducible hifiasm segfault traced to pathologically high organelle k-mer frequency.

Assembly

hifiasm 0.25.0, default parameters except -f0 (bloom-filter override, appropriate for this genome's small size — the default is calibrated for human-scale genomes). Nuclear, organelle-depleted reads: 11.14 Gb (HS2), 11.59 Gb (ALE).

Coverage validation

Single-copy read coverage independently cross-validated two ways: hifiasm's internal ha_pt_gen/purge_dups pass (homozygous coverage threshold HS2 = 157–158×, ALE = 204×) and the raw total-bases ÷ coverage k-mer estimate. Agreement between the two anchors every downstream coverage-dependent parameter below.

Assembly QC

QUAST: HS2 66.6 Mb (N50 947,597, L50 18), ALE 64.5 Mb (N50 1,329,927, L50 16). BUSCO chlorophyta_odb10: HS2 98.9% complete (S:83.9% D:14.9%), ALE 99.1% complete (S:88.9% D:10.1%).

Haplotig purging

purge_dups, manual cutoffs (-l/-m/-u) anchored to validated single-copy coverage using the tool's documented ratio (≈0.25× / 1.0× / 2.7×): HS2 -l 40 -m 158 -u 427; ALE -l 51 -m 204 -u 551. Automatic cutoff detection (calcuts unsupervised) was tested first and rejected — it locked onto a spurious 16× peak instead of true single-copy coverage, producing an unusable, catastrophically over-purged result. Result: HS2 66.6→51.26 Mb (327→78 contigs), ALE 64.5→52.13 Mb (239→72 contigs).

k-mer / heterozygosity

KMC (k=21) → GenomeScope2 (-k 21 -p 2 --fitted_hist) on organelle-depleted, downsampled nuclear reads. HS2: het 1.5%, kcov 124, model fit 68%, len 41.36 Mb. ALE: het 1.55%, kcov 131, fit 61.8%, len 39.94 Mb. Smudgeplot (FastK k-mer database → hetmers → plot) for AB-vs-duplication classification: in progress, not yet complete (§7).

Synteny

MUMmer4 nucmer --maxmatch -c 100, delta-filter -i 90 -l 1000, show-coords -rclT. Run both as self-alignment (each assembly against itself, for within-genome duplication blocks) and cross-alignment (HS2 vs. ALE). Rebuild on the purged assemblies with duplication-block overlay: in progress (§7, Comment 4).

Telomere QC

tidk explore --minimum 5 --maximum 12 for de novo repeat-unit discovery (top hit AAACCCT, 2240 tandem runs >100 bp — a rotation of the canonical plant/green-algal TTTAGGG telomere motif, consistent with Chlorella's phylogenetic position), then per-contig end classification. Variants within 20 kb of a non-telomere-confirmed contig end flagged LOW_near_unconfirmed_contig_end: 35/406 variants (8.6%) genome-wide; 0/6 hydrolysate-stress candidates affected.

Variant calling

DeepVariant + GLnexus joint genotyping (diploid model — to be revisited pending final Smudgeplot classification), pbsv and Sniffles2 for structural variants.

Annotation

SnpEff for variant-effect prediction on a custom database built from the HS2 assembly; functional annotation cross-referenced to UniProt/GO/KEGG via the existing Trinity/Trinotate transcriptome annotation for this strain.

Cross-strain specificity

HS19 (independently NaOCl-selected mutant, GATK HaplotypeCaller short-read pipeline, same HS2 reference) candidate lists — strict (n=13) and loose/permissive (n=86) — compared to ALE's 6 hydrolysate candidates by gene symbol: 0/6 overlap with strict, 1/6 (ODP25) with loose.

05

Response to expert review

An expert reviewer raised six methodological concerns on an earlier version of this analysis. All six are addressed below; three are fully resolved, three remain open and are tracked in §7.

1Reported heterozygosity (0.0036%) is inconsistent with an apparent two-peak k-mer spectrum; the second peak may reflect duplication or repeat content rather than true heterozygosity. Recommended Smudgeplot and self-synteny analysis.

Response

Confirmed founded. Three independent lines of evidence now converge on duplication rather than classical heterozygosity: self-synteny blocks at 100.0% identity (too perfect for allelic variation), elevated BUSCO duplication (14.9%/10.1%), and purge_dups independently flagging 23%/19% of each raw assembly as duplicate content — difficult to reconcile with a 0.0036% heterozygosity figure under a simple diploid model.

Status: pending Smudgeplot (the definitive AB-vs-duplication test) is queued but not yet complete.
2HS2 (66.6 Mb) and ALE (64.5 Mb) assembly sizes differ by ~2.1 Mb — real deletion, or an assembly-processing artifact?

Response

Traced to the root cause: purge_dups had been applied to HS2 only, and with miscalibrated automatic cutoffs. Rerun consistently on both assemblies with coverage-anchored manual cutoffs (§4). Once purged identically, the gap shrinks from 2.1 Mb to 0.87 Mb and reverses direction — the original difference was predominantly a processing artifact, not a real ALE-lineage deletion.

Status: resolved
3T2T completion isn't required for this comparison, but caution is warranted for SNPs/SVs near contig ends.

Response

Agreed. Per-contig telomere classification already existed (tidk-based); now explicitly propagated as a confidence annotation on every reported variant (§4).

Status: resolved — 35/406 variants (8.6%) flagged; 0/6 candidate genes affected.
4If ALE is a direct HS2-derived mutant, structural differences should be minimal — given the duplication signal, the synteny figure should show duplicated regions as boxes, which it currently does not.

Response

Correctly identified a gap between two analyses run separately but never combined: the existing figure shows only cross-genome synteny restricted to uniquely-matching contigs, which by construction excludes the duplicated/multi-mapping content that would appear as boxes. The self-synteny duplication data needed to close this gap already exists (Comment 1) — it was never overlaid.

Status: pending Figure rebuild on the corrected, purged assemblies, with duplicated blocks overlaid as boxes on the cross-genome synteny backbone.
5In a duplicated genome, "1:1" orthology/synteny assignments risk misassigning paralogs.

Response

Agreed — a material risk given the confirmed duplication content. Every reported candidate's coordinates will be cross-referenced against the self-synteny duplicated-block regions; anything falling inside one will be explicitly flagged rather than reported as unambiguous.

06

Reading it together

The overall shape of the evidence points toward a targeted, few-locus explanation rather than wholesale genomic upheaval: the two genomes remain structurally collinear, the size difference that once looked like a deletion turns out to be a processing artifact, and the ALE-specific coding changes that do exist cluster tightly around one biochemical function — clearing reactive aldehydes — rather than scattering across unrelated pathways. Three independent variants landing in the same functional neighborhood is not what you'd expect from noise. The frameshift in GLOX is the mutation most worth leading with: high-impact, directly enzymatic, directly substrate-relevant to HMF.

07

What's needed to close the gap

Open, in priority order

  • HMF-only selection comparison. The most direct confirmatory test available: do the same candidate loci shift under HMF-only pressure, independent of the rest of the hydrolysate cocktail? Raw short reads exist; they need mapping onto the new purged HS2 reference (not the old, incompatible short-read reference) before the comparison is trustworthy.
  • Smudgeplot (Comment 1) — the direct heterozygosity-vs-duplication test; currently the §1 conclusion rests on corroborating signals rather than this purpose-built measurement.
  • Duplicated-block overlap check on the candidate genes (Comment 5) — not yet run against this specific gene list.
  • Synteny figure rebuild with duplication boxes (Comment 4) — pending the purged-assembly synteny rerun.
  • Ploidy-correct variant re-calling — original calls assumed a ploidy model made before the heterozygosity-vs-duplication question was resolved.
  • Phenotype data. Quantified tolerance data (growth curves, IC50/MIC for hydrolysate or HMF, ALE vs. HS2) — the actual phenotype half of "genotype-to-phenotype" — not yet integrated.
Pipeline: hifiasm 0.25.0 → corrected purge_dups → KMC/GenomeScope2/Smudgeplot → MUMmer4 → DeepVariant + GLnexus → SnpEff → Trinotate GO/KEGG/UniProt cross-reference. Evidence-tier language throughout (confirmed / pending / open) is deliberate — unmarked claims in §1–3 are directly measured; §7 is the explicit boundary of what's been verified so far.
